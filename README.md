# BrandOS

AI-Powered Content Generation Engine for Small Businesses.

## Description

BrandOS is a SaaS platform that helps small businesses generate marketing content using Artificial Intelligence.

Users can create:

- Blog outlines
- Social media captions
- Email drafts

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- Prisma ORM

### Database
- PostgreSQL

### AI
- OpenAI API

### Deployment
- Vercel
- Render
- Neon PostgreSQL

## Features

- User authentication
- Business profile management
- AI content generation
- Content history
- SEO analysis
- Tone analysis
- Dashboard analytics
